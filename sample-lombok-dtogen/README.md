# Sample project using java2ts with Lombok and DTOGen

This project shows how java2ts converts Java model classes that use [Lombok](https://projectlombok.org) and [DTOGen](https://github.com/manoelcampos/dtogen) into a TypeScript file.
For a project with plain Java classes and hand-written DTO records, check the [base sample](../sample).

It has:

- JPA entities ([Person](src/main/java/io/github/manoelcampos/java2ts/sample/model/Person.java) and [Country](src/main/java/io/github/manoelcampos/java2ts/sample/model/Country.java)) whose getters are generated by [Lombok](https://projectlombok.org);
- DTO records generated by [DTOGen](https://github.com/manoelcampos/dtogen) (`PersonDTO` and `CountryDTO`);
- a [base interface](src/main/java/io/github/manoelcampos/java2ts/sample/model/BaseModel.java) extending `Serializable` (ignored in TypeScript) and an [abstract base class](src/main/java/io/github/manoelcampos/java2ts/sample/model/AbstractBaseModel.java);
- a Lombok [`@Value` class](src/main/java/io/github/manoelcampos/java2ts/sample/dto/ApiError.java), whose final fields become `readonly` properties;
- an [enum](src/main/java/io/github/manoelcampos/java2ts/sample/model/Status.java), a [record](src/main/java/io/github/manoelcampos/java2ts/sample/model/Phone.java) and generic records ([PageResponse](src/main/java/io/github/manoelcampos/java2ts/sample/dto/PageResponse.java) and [Report](src/main/java/io/github/manoelcampos/java2ts/sample/dto/Report.java));
- Jakarta Validation, JSpecify and Jackson annotations, which define required, nullable and ignored properties;
- [custom type mappings](../README.md#8-custom-type-mappings) with nested generic types;
- [validation schemas](../README.md#9-generating-validation-schemas) generated from the Bean Validation annotations,
  using Zod 4 (which implements [Standard Schema](https://standardschema.dev)) with Brazilian Portuguese messages.
  The `Phone` schema is excluded from the generation and written by hand in [frontend/validation.custom.ts](frontend/validation.custom.ts).

The plugin configuration is in the [pom.xml](pom.xml). JavaDocs are copied to the TypeScript file by default (set the `java2ts.javadoc` property to `false` to disable it).

## Running

The sample uses the java2ts version that is the same as its own version, so install the plugin first:

```bash
# From the repository root
mvn -f java2ts/pom.xml install
mvn -f sample-lombok-dtogen/pom.xml compile
```

The results are the [frontend/models.generated.ts](frontend/models.generated.ts) and
[frontend/validation.generated.ts](frontend/validation.generated.ts) files.
You can check that they compile (in strict mode) and that the schemas accept valid objects and reject invalid ones
(using [frontend/validation.check.ts](frontend/validation.check.ts)) with:

```bash
cd sample-lombok-dtogen/frontend
npm ci
npm run check
```

The generated files are committed so that you can see the result without building the project.
The CI fails if the committed files differ from the ones generated by the current plugin version.
